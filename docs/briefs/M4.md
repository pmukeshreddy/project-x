Implement usable checker construction from actual contract/scenarios: generated worker adapter invokes real Click public interfaces, ordinary observations return to controller, expected relations and hidden case values remain controller-only. Implement validated source-only submission over declared contract roots. Reject traversal/absolute/ambiguous paths, duplicate entries, symlinks/hardlinks/device entries, decompression/size bombs, disallowed files/build/dependencies and attempts to replace controller code/results. Rebuild candidate from clean B using M3; never import candidate/build hooks/deserialization on host, never transfer installed packages/caches/agent runtime. Implement `GradingService.grade(task_version: ArtifactRef, submission: ArtifactRef, case_seed: int) -> OperationResult` with exact types integrated to M0. Freeze seed-derived complete case manifest; all mandated families always present. Enforce each expected probe exactly once with bounded output/schema/type/ID checks; missing/duplicate/skip/forged `passed` output cannot count as receipt. Binary reward one only for all required feature+preservation checks and no protocol violation. Distinguish candidate build/import/crash/limit failures (valid zero) from proven supervisor/platform failure (invalid measurement), with actual logs and preserved same submission/seed for outage retry.

Report discrepancies rather than silently alter contract/checker. Do not make H output the implicit specification. Additional constraints found in H return to M2 and invalidate dependent evidence.

These must use real submission→rebuild→worker→controller path to count as adversarial gate evidence. Unit doubles alone don't count. Real failures can be investigated and repaired under explicit evidence; don't hide them.
