# Factory construction join

`Factory.construct(candidate, inputs=BuildInputs(...))` now obtains the actual selected source prerequisite, verifies the exact SourcePair candidate, and delegates to the real TaskBuilder. The parent Registry construct job directly consumes candidate, source disposition and a frozen request containing the exact builder JobSpec. Every opaque consumed reference is explicitly registered. Successful outputs are the actual BUILT T0, a repair-history artifact and the parent result receipt. Missing authored inputs produce a selected blocked result; rejected source never enters the builder.

TaskBuilder's new `job_spec(inputs)` freezes its existing exact input/policy identities without enqueueing or assembly; `build` now calls that same method. Factory uses it to recover the selected child instead of guessing whether assembly occurred. A completed builder is reused. An unknown pre-freeze builder attempt remains unknown; no automatic assembly retry is permitted. A parent interrupted before its freeze can recover an already completed child while leaving parent overhead unknown. Parent and child pending-publication capabilities replay their original bytes without assembly.

Factory parent costs are incremental controller/publication costs. Original source imports and builder work remain in their own selected jobs, with exact upstream result and job bindings retained in the parent receipt. Parent wall excludes the builder-call interval. A new attempt is not represented as a new copy of an existing task or source cost.

The current history projection retains the approved M3 neutral repair (with its actual patch/evidence and recorded base-image identity) and explicitly keeps `complete=False`. It does not infer zero source/authoring/verifier repairs from missing generation journals or claim that manually supplied fixtures are a model-authored feature. Authenticated M2 history import, candidate/stage budget enforcement and actual authoring orchestration remain the next Factory work; qualification must keep this incomplete history provisional. Source, contract, scenario, verifier or solver-byte changes still require the actual builder to freeze a new root.
