## Provenance and split

The source pair uses an admissible cutoff of `2026-02-13T20:25:22Z` and the label `reconstructed_specification`. Public evidence exposes current request text and some edit timestamps but does not provide a defensible preimplementation body revision. The first retained implementation commit also predates PR creation. The authoring bundle therefore carries the reconstruction caveat. It includes a comment only if both `created_at` and `updated_at` precede the cutoff.

The upstream repository, head fork, PR, and linked issue form one deterministic train component:

- `pallets-click` fork-related to `rc2215-click`

All four resolve to `component-72074964ad6e8ca207dffa2f4800c58bf828d64221f8f6fe8cfd00cd869535e1` in `train`. The closure engine also covers backport, copied-code, monorepo, and descendant relations, rejects conflicting explicit assignments, preserves relation proof, and retains dependency relations for review without treating them as proof of independence.
