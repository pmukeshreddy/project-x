## Review finding dispositions

1. **Repository-local Git execution:** every diff uses `--no-ext-diff` and `--no-textconv`; hooks, paging, prompts, filters through checkout, and source execution are absent. A hostile local `diff.external` regression confirms reconstruction, path inspection, blob reads, and archiving do not run the helper.
2. **Promisor lazy fetching:** every Git process sets `GIT_NO_LAZY_FETCH=1`. An incomplete blob-filtered promisor fixture fails explicitly while its object inventory remains unchanged. The real-cache before/after inventory is also identical.
3. **Provenance and chronology:** CandidateRecord, SourcePair, and `PullRequestIntakeResult` carry the same validated label; the typed artifacts are schema v2. Intake orders issue creation, admissible cutoff, earliest source author/committer time, integration, recording, and retrievals. `historical_request` additionally requires an exact issue snapshot captured by the cutoff with consistent update time. Positive historical and reconstructed fixtures and contradictory/post-cutoff negatives pass.
4. **Disconnected squash:** squash intake requires the complete declared source chain to descend contiguously from B and end at the declared head; an unrelated orphan with H's tree is rejected.
5. **Rewritten rebase:** rebase derives a distinct contiguous integrated span ending at H and records its source-to-integrated mapping. Exact delta fingerprints preserve path, mode, binary identity, and every added/removed byte while allowing unchanged context movement. A genuine cherry-picked rewrite passes; reordered, interleaved, duplicate/ambiguous, and whitespace-altered deltas reject. Stable whitespace-insensitive patch IDs are not used as semantic proof.
6. **License binding:** the API object, cached bytes, and bounded local blob bytes must match in B and H. Arbitrary cached text and an H license change both reject before a verified license is emitted.
7. **HTTP redirect and deadline policy:** the entire DNS/connect/redirect/read operation runs in a child process under a monotonic deadline and byte cap. Each hop and the final URL must remain credential-free HTTPS on the requested origin; local-host and nonpublic literal targets reject. The actual chain is preserved for live acquisition.

The boundary recheck also found and closed a process cleanup issue after the initial seven-finding patch. Git commands run in owned process groups. Cleanup signals the group even after the leader exits and verifies no live member remains. This macOS environment produced `PermissionError` for `killpg`; the tested equivalent fallback enumerates only that process group with `/bin/ps`, kills every live member directly, treats zombies as terminated, and repeats until empty or a one-second fail-closed deadline. Regressions cover leader success, leader failure, timeout, and output-limit cleanup with background descendants.
