It freezes source lineage, locked-test roster, A/B/C/D protocols, matched budgets, paired trials and explicit case seeds; validates complete trial accounting; computes honest all-assigned and valid-only arm rates and task/family paired uncertainty; records an external-corpus adaptation funnel; and performs authenticated historical audits against real Registry, rollout and M4 grade records with M5 external human trust and quarantine tracing.

The available evidence is 13 passing owned CPU unit diagnostics. These diagnostics are not evaluation results, task qualification, human approval, or evidence that any learned arm exists. The metadata-only SWE-Bench++ feasibility review remains in `docs/evidence/M8/baseline-feasibility.md`; no dataset rows, solutions or locked-test payloads were acquired.

`EvaluationService.evaluate(config)` is the remaining implementation dependency. It will be wired only to the actual M7 runner API after publication, passing each frozen case seed exactly once and validating the returned rollout and M4 receipt. It will not use an injected or always-blocked adapter.
